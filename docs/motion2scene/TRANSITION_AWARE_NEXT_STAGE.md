# Next stage: executable, observable training contrasts

The working paper is **Motion2Scene: Transition-Aware Counterfactual Environments
for Humanoid Traversal Learning**. Its proposed contribution is a data-construction
method: achieved command transitions condition scene proposals; paired physical
outcomes determine labels; a fixed perception-conditioned learner tests usefulness
against execution-aware analytic construction. The learning advantage remains a
hypothesis, not an established contribution.

## Evidence gates and order of work

1. **Diagnose the shared failure — completed.** Twenty frozen selectors, all 214
   input dimensions, hidden/logit ranges, 9,240 donor/group interventions and exact
   observation groups. Large normalized state extrapolation supports a state-support
   problem. Outcome aliasing does not force an action error in the finite corpus.
2. **Measure available action advantage — completed.** Twelve new paired Isaac Lab
   commands on the six inspected conditions. The middle-height seed-8512 encounter
   is rescued by d040; both low-height encounters remain unsupported by either action.
3. **Qualify the common learner repair — development execution study.** Apply the
   same fixed-scale regularized linear learner to all four original data arms and
   execute all six conditions. This joint control changes capacity, scaling and
   regularization; it cannot isolate normalization as the sole cause. Keep all
   original models frozen and all 480 pending v1 assignments operationally paused.
4. **Construct transition-aware data on multiple development carriers — next main
   method experiment.** Use achieved empty-scene command transitions, including
   entry and exit, to replace the complete-reference proposal evaluator. Retain the
   existing local initializer and bounded pattern search. Give analytic and learned
   methods the identical acquired transition bank. Record all proposed, rejected,
   labeled and failed acquisitions. A proxy forecast is not a physical label.
5. **Freeze the substantive comparison only after the common interface works.**
   Compare uniform, execution-aware analytic, original reference-based Motion2Scene,
   transition-aware no-contrast, and full transition-aware Motion2Scene. Use the
   existing 24/48/96 complete-example budgets, separate fits at every budget and five
   optimizer seeds. Five arms × three budgets × five seeds means 75 fits, not fifteen
   fits with three checkpoints. Register rollout cost before assigning the final panel.

## Bounded development design before scaling

Start from the already audited source 41002, then acquire and qualify at least two
additional development carriers under the same 0.30 s request and 3.3 s return
contract. Historical whole-motion qualifications do not qualify their switches.
Select development ancestors before labels; do not use reserved final candidates
9490001–9490008. Keep failed acquisition and transition qualification in the denominator.
No second carrier has yet been qualified under this switching contract.

For each qualified carrier and physics seed, bind both empty command executions to
matched pre-decision state/action/token histories. Store the sensor packet at the
actual decision and the achieved 50 Hz body trajectory. Use identical transition
information for analytic and learned proposals. The present forecast audit tests
35 old scenes with one empty-transition seed; it proposes no new accepted placement.

Construct related critical, raised/removed and blocked encounters around common
contexts. Complete both physical command labels; preserve all four outcomes. Measure
whether the causal packet changes when the useful action changes. Report useful
contrast yield per requested scene and per acquisition cost, not only retained yield.
Do not force critical-scene quotas by uncharged retries. Retain a fixed common
background mixture in every learner's corpus.

The first development factorial crosses reference versus achieved-transition
construction with original versus common repaired learner. Keep sensors, thresholds,
transition guard and scorer fixed where meaningful. If sensing must change, register
that as an additional interface version and recollect its paired labels. The present
linear control is a joint learner repair; a fixed-scale original MLP and a comparably
regularized linear control can isolate scaling/capacity on development training and
validation data before selecting the shared learner. No tuning on final test outcomes.

At 0.30 s, low and middle beams already produce upper hits and free-space queries in
the six inspected conditions. Visibility alone is insufficient: low beams remain
both-fail. Measure informative, legal and successful request times separately; do
not assume their intersection is a single interval or that a later decision helps.
Keep the scripted upper/lower-ray selector as a separately executed comparator.
Refusal predicts command-bank inadequacy and continues walking; it is not safe stopping.

## Final experiment and claim boundary

Freeze an independent layout distribution and genuinely new source ancestors after
the revised method is stable. The six inspected conditions remain valid tests of the
original models but are development data for every revision. The 430xx ancestors are
already inspected and are not newly untouched tests. Reserved candidate IDs are not
acquired sources; generation, canonical duplicate checks and switching qualification
must precede final-source evaluation, with all derivatives grouped by ancestry.

Primary endpoint: source-averaged contact-qualified passage with first-episode
stability on the prespecified traversal suite. Report actual contact forces, return,
resets and later recovery separately; report unnecessary crouching and blocked-scene
infeasibility detection in their own suites. Include paired optimizer-seed differences
and source-grouped uncertainty; repeated fits do not create independent datasets.
Choose a superiority or prespecified noninferiority/cost claim before final outcomes.
Charge fitting/teacher costs, transition acquisition, search, rejected proposals,
independent verification and both physical labels. Equal labels and equal acquisition
budgets answer different questions.

The project has an embodied learning interface and a measured failure mechanism.
It still lacks multi-carrier transition-aware acquisition, the 24/48/96 learning
comparison, actual final-source transfer, and a manuscript whose strongest claims
survive those results. An analytic improvement is evidence for a stronger comparator,
not evidence that the learned generator has earned its cost. Hardware and another
skill family are not prerequisites for this scoped simulation study.
