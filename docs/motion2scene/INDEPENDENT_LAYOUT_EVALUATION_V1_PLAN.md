# Next evaluation: fixed development learners on independent layouts

Written after the 38-pair development corpus and twenty fixed fits, before consuming
any reserved-layout physics outcome. This is an execution plan, not a physics launch
manifest or an unseen-performance result. The generator, all twenty checkpoints,
0.30 s command contract and twelve layout coordinates remain frozen.

The development finding is unfavorable to the proposed generator: nine of nine
Motion2Scene generated scenes have both commands fail, while four of eight analytic
scenes make d040 useful. This does not establish a downstream ranking. It makes the
analytic comparator essential and prohibits quietly repairing or replacing the
Motion2Scene assignments before this comparison.

## Required order

1. **Prerequisite completed:** all twelve learned-command integration executions on
   already observed scenes match direct features, model requests, complete trajectories
   and passage outcomes. [Measured check](evidence/learned-command-check-result.json).
   This qualifies the implementation; it does not consume independent layout outcomes.
2. Bind each of the twenty completed checkpoints to the original twelve reserved
   layouts and physics seeds 8511/8512. Materialize scene files with the same source
   route geometry and validity checks. Do not redraw or reject a test because the
   robot fails; infrastructure omissions and unsupported cases remain explicit.
3. Freeze a master assignment plus bounded serial execution chunks. Twenty policies
   × twelve layouts × two physics seeds gives **480 traversal executions**. The
   absent, raised and blocked suites add twenty × three × two = **120 controls**.
   Shared controls in training do not eliminate these actual policy evaluations.
4. Run one layout/physics-seed block across all twenty policies in declared arm/seed
   order. Each block reserves at most 20 × 375 / 3600 = **2.083334 contended GPU h**;
   recheck rolling daily/weekly use before every block. The full worst-case ceiling
   is 62.5 h and is not authorized as a single batch under the standing 8 h/day and
   24 h/week limits. Use measured cost for scheduling, retain the 7500 MiB floor,
   and resume the unchanged assignment on subsequent days if required.
5. Publish all assigned outcomes, paired optimizer-seed differences and layout/physics
   groups. Begin no new generator architecture and make no training changes from
   these results. The final source-transfer study follows a distinct pre-generation
   manifest and duplicate/qualification checks for reserved candidate IDs.

## Measurement and interpretation

The primary development comparison is Motion2Scene minus strong analytic data at
**eleven complete training encounters per arm**. Use the existing explicit <1 N
beam-force criterion, passage, reset and recovery rules. Report measured maximum
forces as well as the thresholded result. Neutral commitment, d040 request and
refusal-with-neutral-fallback retain their deployed meanings. Refusal is not stopping.

Report traversal success on the twelve-layout suite for each fixed fit and physics
seed, then paired differences between arms. Report unnecessary crouching on absent
and raised controls, and infeasibility detection versus executed avoidance on blocked
controls separately. Do not pool those denominators into one headline success rate.
The source is still 41002: layout counts and optimizer seeds are not new source
replication. There is no source-held-out confidence claim from this panel.

Before the larger study, run the same scripted sensing, blind and privileged baselines
on the same panel and add phase-only/observation-swap diagnostics with a separately
frozen assignment. These are additional costs, not hidden within the 600 learned
policy cells. The full 24/48/96 complete-label budgets need independent fits; the
current twenty models at size eleven do not constitute three data-efficiency points.

A post-fit development audit also finds identical 214-value observations with different
outcomes across thirteen scenes. This is evidence of an information limitation at the
fixed decision, not a reason to rewrite labels. If methods fail on common encounters,
separate sensing/transition support from scene-generation quality. Any revised interface
belongs to a new development study, followed by a new independent test reservation.

A favorable main-paper claim remains contingent on fresh-source, matched-cost evidence.
If analytic matches or beats Motion2Scene, report that result and narrow the learned
advantage claim accordingly. Training loss and the observed-scene integration check
cannot establish superiority, noninferiority or data efficiency.
